# Devices

1. Router

Layer 3 Network device
Forwards traffic based on IP
Can be within a layer 2 switch
Connects different networks (LAN, WAN...)

2. Switch

Layer 2 Data Link layer
Forwards taffic based on MAC
Can provide Power over ethernet cable
Application-specific integrated circuit ASIC
Can contain routing functions, multilayer 2 and 3

3. Firewall

Filter traffic by port or app (Traditional)
NGFW can identify context for traffic
Can encrypt traffic (VPN between sites)
Can be layer 3 devices (Sits on the ingress/egress point, can have Network Address Translation NAT and DNS

4. IDS and IPS

Intrusion detection system and Intrusion Prevention system
Watch network traffic, prevents or detects exploits, buffer overflows, cross-siste scripting and other

5. Load balancer

Multiple servers
Invisible
Large-scale and high fault tolerance

Configurable, TCP offload, SSL offload, Caching, Priorization, Content switching.

6. Proxies

Located between users and extenral networks
Recieves requests from users and sends the requests on their behalf.
Acces control, URL filtering, content scanning
Apps may need to know how to use the proxy (explicit) or not (transparent)

7. NAS vs SAN

NAS Network Attached Storage
Connection to a shared storage devide accross the network.
File-level acces

SAN Storage Area Network
Looks and feels like a local storage device, Block-level access
Efficient at read and write

Storage requires a lot of bandwitch, optimize the use of SAN or NAS.


8. Access point (AP)

Bridge to extend the wired network into the wireless network.
Layer 2 
Can be configurated individually (access policy, security, AP configs)

LAN controller gives control over the entire management of AP in the network, can deply now APs, performance and security monitoring, configure and deploy changes everywhere, reports on AP use
PRopietary system, probably may need to be the same manufacturer as the APs
