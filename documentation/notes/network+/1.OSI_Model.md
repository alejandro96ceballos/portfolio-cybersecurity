7. Application

- The visual layer
- HTTP, FTP, DNS, POP3...

6. Presentetion

- Character encoding, aplication encryption, often combined with layer 7

- SSL/TLS
5. Session

- Communication management layer
- Control protocol, tunneling protocols.

4. Transport 

- The "post office" layer
- TCP, UDP
- Transmitting data from one device to another, reconstructing pieces of the data...

- TCP segment, UDP segment
3. Network

- The "routing layer"
- Internet protocol IP, subnet masks, routing
- Fragments frames to traverse different networks

- IP address, router, packets

2. Data Link

- Foundation of comunication
- MAC address layer
- Data Link Control Protocols DLC
- The "switching" layer

- Frame, MAC address, Extended Unique Identifiers, Switch

1. Physical

- Signaling, cabling, connectors
- No protocols

- Cables, fiber and the signal
