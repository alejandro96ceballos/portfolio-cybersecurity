# Unicast

One on one communication, just 2 stations involved

Bad Scalability
File transfer, web surfing...

Need to create separate communication channels to manage.

# Multicast

One to many of many communication

Data sent simmulatously to multiple systems at once.
Very specialized, difficult to scale on large networks

# Anycast

One to one of many
Data is delivered to the closest interface
DNS uses this

# Broadcast

One to all
Send data to every other system
Limited by the domain
ARP request, routing updates
