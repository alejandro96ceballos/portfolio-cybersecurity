GSM and CDMA evolution to use by all providers for mobile devices
150mbits/s

LTE-A

## 5G

10 gigabits/s

Big impact over bandwith, larger data transfers, monitoring and cloud processing

# Satellite networking

High cost and complexity, not as fast as terrestrial
Good for remote sites with no connectivity
High latency
Requires line-of-sight for function
