### Virtualization NFV

Instead of 100 physical servers and infrastructure we build 100 virtual servers on a large server.

Manage them with hypervisor, same functionality as the physical devices.

Easy to deploy or retire virtual devices.

VMs, containers...

## Virtual private cloud VPC

Resources pool in public cloud

Separate VPC for diferent parts of a organization connected with transit gateway (cloud router)

Separate the transit gateway with a VPN tunnel for security

Connect the virtual environment to the public internet with a VPC Gateway, and with NAT we let the VPC connect with external resources with security options

Connect with another VPC on different providers with a VPC Endpoint without acces with public internet

## Cloud Firewalls

Secutiry groups and lists allow to set different security rules for the cloud environment just as a physical firewall

Layer 4 for TCP UDP rules

LAyer 3 for specific IPs

Broad rules are not a good idea, granularity may be needed using security groups that permit creating custom groups of devices
