## CDN

Content Delivery Network

Moving data takes time, to speed up we have CDN

Distributed caching servers that duplicate the data to make routes shorter and speed up data transport process
Users get data from local servers
Invisible to the user

## VPN 

Secure private data traversing a public network, encypted through an insecure media

- Concentrator device
Encryption/decryption access deice
Often inside firewall

Can be deployed through hardware or software (for smaller builds)

Used with client software usually


## QoS

Traffic and packet shaping
Control by bandwitch usage or data rates to give priorities on applications or packets
Important apps get higher priorities
Can be managed through routers, firewalls, dedicated devices...


## TTL

Timer that sets a number of iterations or hops to drop a certain packet and consider it "lost"
Used for clear caches also
Prevent routing loops if there is one misconfigured, specially on static routing.
TTL gets down by 1 everytime a packet passes through a router. Linux default is 64, windows is 128
Once a router gets a 0 TTL packet it is discarded
Usual hops for accessing data is between 12 and 16
